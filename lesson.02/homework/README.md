# Задания по кортежам, множествам и словарям

## Кортежи

### Задание 1. Изменение кортежа через список

Дан кортеж:

```python

```

Преобразуйте его в список, добавьте число `6`, а затем преобразуйте обратно в кортеж.

### Пример результата

```text
(1, 2, 3, 4, 5, 6)
```

### Задание 2. Срез кортежа

Дан кортеж:

```python
fruits = ("apple", "banana", "cherry", "date")
```

С помощью среза создайте новый кортеж, содержащий только первые два элемента.

### Пример результата

```text

```

### Задание 3. Распаковка кортежа

Дан кортеж:

```python
data = (10, 20, 30, 40, 50)
```

С помощью распаковки:

* первое значение сохраните в `a`;
* второе значение сохраните в `b`;
* остальные значения соберите в `others`.

### Пример результата

```text
a: 10
b: 20
others: [30, 40, 50]
```

## Задание 15 ⭐. Статистика магазина

Дан словарь с количеством проданных товаров:

```python
sales = {
    "Ноутбук": 7,
    "Мышь": 25,
    "Клавиатура": 14,
    "Монитор": 9,
    "Наушники": 18
}
```

И словарь с ценами:

```python
prices = {
    "Ноутбук": 85000,
    "Мышь": 3500,
    "Клавиатура": 7200,
    "Монитор": 32000,
    "Наушники": 11500
}
```

Необходимо:

1. посчитать общую выручку магазина;
2. найти товар, который продали в наибольшем количестве;
3. найти товар, который принёс наибольшую выручку.

### Пример результата

```text
Общая выручка: 1307700

Больше всего продано: Мышь
Количество: 25

Наибольшая выручка: Ноутбук
Выручка: 595000
```
