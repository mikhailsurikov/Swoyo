# Домашнее задание № 3. Строки

## Задание 1. Длина строки и символы

Дана строка:

```python
text = "Programming"
```

Выведите:

* длину строки;
* первый символ;
* последний символ.

### Пример результата

```text
Длина: 11
Первый символ: P
Последний символ: g
```

## Задание 2. Работа со срезами

Дана строка:

```python
text = "Python programming"
```

1. слово `Python`;
2. слово `programming`;
3. всю строку в обратном порядке.

```text

programming
gnimmargorp nohtyP
```

## Задание 6. Проверка имени файла

Попросите пользователя ввести имя файла.

Если имя файла заканчивается на `.py`, выведите:

```text

```

В противном случае:

```text

```

Проверка должна работать независимо от регистра расширения.

### Пример работы

```text
Введите имя файла: homework.PY

```

# Задания со звёздочкой ⭐

## Задание 11 ⭐. Палиндром

Попросите пользователя ввести фразу.

Необходимо определить, является ли она палиндромом.

При проверке:

* не учитывайте регистр;
* не учитывайте пробелы.

Палиндром одинаково читается слева направо и справа налево.

### Пример

```text
Введите текст: А роза упала на лапу Азора
Это палиндром
```

---


Посчитайте количество русских гласных букв в строке.

Учитывайте как строчные, так и заглавные буквы.

### Пример результата

```text
Количество гласных: 9
```

## Задание 13 ⭐. Проверка пароля

Попросите пользователя ввести пароль.

Пароль считается корректным, если:

* состоит только из букв и цифр;
* содержит хотя бы одну заглавную букву;
* содержит хотя бы одну строчную букву;
* содержит хотя бы одну цифру.

### Пример 1

```text
Введите пароль: python2026

```

### Пример 2

```text

Пароль должен содержать хотя бы одну цифру
```
