## Задание 1. Статистика текстового файла

Создайте файл:

```text

```

С содержимым:

```text
Python используется для веб-разработки.
Python подходит для автоматизации.
Изучать Python интересно.
```

Напишите программу, которая с помощью `with`:

1. читает файл;
2. выводит количество строк;
3. выводит количество символов во всём тексте.

Количество символов считайте вместе с пробелами и переносами строк.

В примере после последней строки дополнительного переноса строки нет.

### Пример результата

```text
Строк: 3
Символов: 100
```

# Проект: Телефонный справочник. Часть 7

Продолжите работу с телефонным справочником.

Теперь контакты должны сохраняться между запусками программы.

Используйте:

* `pathlib`;
* JSON;
* `with`.

В этой версии сохраняются объекты:

```python
PersonalContact
WorkContact
```

## Структура данных

Добавьте папку:

```text
data/
```

Контакты храните в:

```text
data/contacts.json
```

Если папки `data` нет, программа должна создать её автоматически при создании объекта `PhoneBook`.

---

## 1. Сохранение контактов

Добавьте в `PhoneBook` метод:

```python
save()
```

Он должен сохранять контакты в JSON.

Для каждого контакта сохраняйте:

* тип контакта;
* имя;
* телефон;
* дату создания;
* `relation` для личного контакта;
* `company` для рабочего контакта.

### Пример JSON

```json
[
    {
        "type": "personal",
        "name": "Анна",
        "phone": "+79991234567",
        "created_at": "2026-09-15 18:30:00",
        "relation": "друг"
    },
    {
        "type": "work",
        "name": "Иван",
        "phone": "89991234567",
        "created_at": "2026-09-15 18:35:00",
        "company": "SkyPro"
    }
]
```

---

## 2. Загрузка контактов

Добавьте метод:

```python
load()
```

Он должен загружать данные из:

```text
data/contacts.json
```

Если файла ещё нет, справочник остаётся пустым.

Если JSON повреждён, обработайте:

```python
json.JSONDecodeError
```

и выведите:

```text
Не удалось загрузить контакты
```

---

## 3. Автоматическое сохранение

После:

* добавления;
* изменения;
* удаления

контакта автоматически вызывайте:

```python
save()
```

При запуске программы один раз вызывайте:

```python
load()
```
