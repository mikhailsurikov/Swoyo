# Домашнее задание. Виртуальные окружения и управление зависимостями

## Формат сдачи

Для каждой задачи приложите:

* скриншот терминала, **или**
* копию соответствующего вывода терминала.

По результату должно быть понятно, что задание выполнено.

Папки виртуальных окружений `.venv` сдавать не нужно.

---

## Задание 1. Виртуальное окружение и установка библиотеки через pip

Создайте отдельное виртуальное окружение `.venv`.

После его активации **с помощью `pip`** установите библиотеку:

```text
Faker
```

Проверьте:

* версию Python;
* какой Python используется;
* что `Faker` установлен;
* установленную версию `Faker`;
* список пакетов окружения.

После этого деактивируйте виртуальное окружение и сравните путь к Python до и после деактивации.

### Что сдавать

Скриншот терминала или копию вывода, где видны:

```text
версия Python
путь к Python
Faker и его версия
```

---

## Задание 2. Установка конкретной версии, обновление и удаление через pip

Создайте отдельное виртуальное окружение.

С помощью `pip` установите:

```text
colorama версии 0.4.5
```

После этого:

1. проверьте установленную версию;
2. обновите `colorama` через `pip`;
3. снова проверьте версию;
4. удалите библиотеку через `pip`;
5. убедитесь, что пакет больше не установлен.

### Ожидаемый результат

До обновления:

```text
Version: 0.4.5
```

После обновления должна быть установлена более новая доступная версия.

После удаления проверка пакета должна показать, что он не найден.

### Что сдавать

Скриншот терминала или копию вывода, где видны:

* версия до обновления;
* версия после обновления;
* результат проверки после удаления.

## Задание 3. requirements.txt и восстановление окружения через pip

Создайте новое виртуальное окружение.

С помощью `pip` установите:

```text
Faker
tabulate
humanize
```

Зафиксируйте зависимости окружения в:

```text
requirements.txt
```

После этого создайте второе чистое виртуальное окружение.

Используя `pip` и готовый `requirements.txt`, восстановите в нём зависимости проекта.

Проверьте, что все библиотеки установились.

### Ожидаемый результат

Первое и второе окружения должны содержать одинаковые версии зависимостей из `requirements.txt`.

### Что сдавать

1. Содержимое `requirements.txt`.
2. Скриншот терминала или копию вывода со списком зависимостей после восстановления второго окружения.

## Задание 4. Добавление и удаление зависимостей в Poetry

Создайте новый проект под управлением Poetry.

Добавьте основную зависимость:

```text
humanize
```

Проверьте, что библиотека появилась в проекте.

После этого:

1. добавьте `Faker`;
2. посмотрите список зависимостей;
3. посмотрите дерево зависимостей;
4. удалите `Faker`;
5. убедитесь, что `humanize` остался, а `Faker` удалён.

### Что сдавать

Скриншот терминала или копию вывода, где видно:

* зависимости до удаления;
* дерево зависимостей;
* зависимости после удаления `Faker`.

Также приложите соответствующую часть:

```text
pyproject.toml
```

## Задание 5. Группы зависимостей Poetry

Создайте новый Poetry-проект.

Добавьте в основные зависимости:

```text
tabulate
```

В отдельную группу разработки `dev` добавьте:

```text
pytest
```

Проверьте зависимости проекта.

После этого удалите `pytest` из группы разработки и снова проверьте результат.

### Ожидаемый результат

До удаления:

* `tabulate` является основной зависимостью;
* `pytest` находится в группе `dev`.

После удаления:

* `tabulate` остаётся;
* `pytest` больше не является зависимостью проекта.

### Что сдавать

1. Скриншот терминала или копию вывода.
2. Соответствующую часть `pyproject.toml`.

# Проект: Телефонный справочник. Часть 8

Продолжите работу над телефонным справочником.

Основную логику приложения менять не нужно.

На этом этапе задача — перевести проект на управление зависимостями через Poetry.

## 1. Настройте Poetry

Настройте Poetry в корневой папке проекта.

После выполнения задания в проекте должны появиться:

```text
pyproject.toml
poetry.lock
```

---

## 2. Добавьте основную зависимость

Добавьте:

```text
tabulate
```

Используйте библиотеку для вывода списка контактов в виде таблицы.

### Пример

```text
Имя    Телефон        Тип
-----  -------------  --------
Анна   +79991234567   Личный
Иван   89991234567    Рабочий
```

---

## 3. Добавьте зависимость для разработки

Добавьте:

```text
pytest
```

в группу:

```text
dev
```

Таким образом:

```text
tabulate → основная зависимость
pytest   → зависимость для разработки
```

---

## 4. Проверьте проект

Проверьте:

* список зависимостей;
* дерево зависимостей;
* содержимое `pyproject.toml`;
* запуск телефонного справочника в окружении Poetry.

### Что сдавать

1. `pyproject.toml`;
2. скриншот или копию вывода терминала со списком зависимостей;
3. скриншот или копию вывода дерева зависимостей;
4. скриншот или вывод работающего телефонного справочника с таблицей контактов.
